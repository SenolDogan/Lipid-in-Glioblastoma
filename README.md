# Lipid-in-Glioblastoma

Integrated lipidomics-metabolomics analysis of glioblastoma (GBM), including the final manuscript files, publication figures, processed result tables, and reproducible analysis scripts.

## Repository Contents

- `manuscript/`: final manuscript (`LIPID.docx`) and supplementary files prepared for submission.
- `figures/main/`: final main figures used in the manuscript.
- `figures/supplementary/`: supplementary and supporting figure panels.
- `results/`: processed result tables generated by the analysis workflow.
- `scripts/`: core analysis, validation, plotting, and document-preparation scripts.
- `external_validation/fontanilles_2024/`: processed external validation outputs based on the Fontanilles et al. 2024 supplementary plasma metabolomics dataset.
- `docs/`: text summaries and supporting documentation.

## Manuscript and Supplementary Files

The manuscript and supplementary files were cross-checked before upload so that all in-text references to supplementary figures and tables match the available supplementary files.

- Main manuscript: `manuscript/LIPID.docx`
- Supplementary figures: `manuscript/Supplementary_Figures.docx`
- Supplementary tables: `manuscript/Supplementary_Tables.xlsx`

## Data Policy

This repository includes processed result tables and derived outputs. Large raw omics quantification files are intentionally not included. Input data are described in the manuscript and can be obtained from the cited public resources.

## Reproducibility

Core scripts are provided in `scripts/`. The final figure-generation scripts are in `scripts/plots/`. Processed outputs needed to inspect the manuscript claims are in `results/` and `external_validation/`.
