# Data Availability

This repository contains processed result tables, figures, manuscript files, and analysis scripts. Large raw omics matrices are not committed to GitHub.

Primary discovery data are described in the manuscript as CPTAC/TCGA GBM 2021 resources (`gbm_cptac_2021`). External validation outputs are provided for the Fontanilles et al. 2024 plasma metabolomics cohort under `external_validation/fontanilles_2024/`.
